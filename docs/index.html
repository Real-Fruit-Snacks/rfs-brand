Mark

The Caps Tile

RFS in Plex Mono SemiBold on a rounded tile (radius 14 of 64), with an Ember rule beneath. Letters are always white. Clear space is one corner radius; the smallest size is 16 px.

Don't rotate it, outline the colour version, recolour the letters, or put it on Ember. The glow is a CSS effect in Nightshift interfaces, never part of an asset.

Covers

Every repo, one layout

A repo's cover is the image under its README one-liner, its site's link preview and its GitHub social preview, all drawn by tools/make-cover.py from docs/assets/cover.toml. A terminal panel by default; a tool with a UI draws itself.

# from the folder that holds both clones
python3 rfs-brand/tools/make-cover.py my-repo/docs/assets/cover.toml   # cover + social preview
python3 rfs-brand/tools/make-org-art.py                                # profile banner, org card, X header
python3 rfs-brand/tools/make-avatar.py                                 # profile picture

# once
pip install fonttools resvg-py pillow

Voice

Plain, specific, dry, honest

No emoji, no exclamation marks, no "blazing", "powerful", "modern" or "seamless". First person singular for one maintainer. Sentence case everywhere.

TraitTest
PlainCould a tired admin at 2 am act on it?
SpecificIs every adjective replaceable with a fact?
DryHumour lives in details, never in the headline.
HonestIs the first limitation visible without scrolling?

Templates

Starting a repo

  1. Copy templates/repo/README.md: one-liner, cover, install, context, what's in it, tested on, known issues, configuration, license.
  2. Work through the settings checklist: description, topics, social preview, branch, releases.
  3. Copy templates/repo/cover.toml to docs/assets/, fill it in and run make-cover.py.
